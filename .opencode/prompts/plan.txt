Project hard constraints (see AGENTS.md — `outline.md` is the source of truth for intent):
- macOS-only for the initial build. iOS/Android/Windows/Web are roadmap.
- Non-blocking UX is core: architecture must decouple writing from AI processing; feedback arrives async.
- Autonomous research should prefer discounted batch processing where possible.
- Slash commands (`/research`, `/fact-check`, `/ignore`) are the canonical editor surface.
- The app is an agnostic watcher/overlay over a plain `.md` folder, not the exclusive owner of the data. Files may be authored/changed by external tools (e.g. Obsidian); react to disk state. The editor's folder tree must mirror on-disk structure exactly.
- UI layout: bare-bones markdown editor in the main pane, right-hand side pane showing AI agent status/progress/results. Editor is plaintext-only for now; markdown rendering and syntax highlighting are roadmap (Vim keybindings + syntax highlighting are high-priority roadmap items).
